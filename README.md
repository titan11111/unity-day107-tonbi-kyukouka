# day107 トンビ急降下 (Unity 6000.3.26f1)

湘南の浜辺で3Dのトンビが人間の食べ物をかっさらうステルス・アクション。

## 遊び方
1. Unity Hub で このフォルダ(day107)を「追加」→ 6000.3.26f1 で開く
2. 初回はスクリプトのコンパイル待ち。**Assets/Scenes 内の任意のシーン**(または空の Untitled)で ▶ Play
   (ワールドは起動時に自動生成されるので、シーンは空でOK)
3. タイトル画面で「スタート」(タップ / Space / Enter)

## 操作
- 左半分ドラッグ or WASD/矢印: 旋回・上昇下降
- 右下 急降下(長押し) / Space
- 羽ばたき: ボタン / F / Shift
- M: ミュート、Esc/Backspace: エンディングからタイトルへ
